Auto Dialer Developer

Muhammad Afzal Kalwar is an auto dialer developer in Islamabad, Pakistan. He is available remote for US/UK/EU dispatch and sales teams that use Google Voice, iPECS, or a Windows dialer.

Published pieces include a Google Voice queue dialer, an iPECS Cloud extension, a PyQt campaign dialer, and an operator console that logs calls. Lists usually start in Excel. Pacing, scripts, and local logs are part of the same job.

He does not publish invented call volumes or client quotes. The repositories and the Chrome Web Store listings are the public record.

Google Voice

Queue dialing from the browser, with the GV Auto Dialer extension and the dispatch console.

iPECS Cloud

A Manifest V3 extension for outbound calling on iPECS.

Windows campaigns

Excel-driven desktop dialers with resume, hotkeys, and local logs.

Operator controls

Scripts, voicemail handling, and a console the operator can actually watch.
